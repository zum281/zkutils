# zkutils

Small set of utils I sometimes use.

## Install

`make install` builds and moves all programs in `~/.local/bin`.
Or just build and put them wherever.

## tc: temperature converter

convert between celsius/farhenheit

### usage

```bash
    tc {c|f} <temperature>
```

## timer

timer from the terminal on macOs.

### usage

```bash
    timer <time>
```

### example

```bash
    timer 1h20m3s
    timer 3m
    timer 40s
    timer 1h30s
```
